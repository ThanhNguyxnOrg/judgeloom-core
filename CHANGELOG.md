# Changelog

All notable changes to **JudgeLoom** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial community health files: `LICENSE`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `CHANGELOG.md`.
- GitHub issue templates (bug report, feature request, question) and pull request template.
- `.github/CODEOWNERS`, `.github/FUNDING.yml`, `.github/dependabot.yml`.
- CodeQL static analysis workflow.
- Release workflow that publishes a GitHub Release on every `v*.*.*` tag.
- `.editorconfig` and `.gitattributes` for consistent cross-platform formatting.

### Changed
- Hardened the existing CI workflow with explicit permissions and concurrency controls.
- Refreshed `README.md` badges and links to point at the canonical repository.

## [0.1.0] - 2025-XX-XX

Initial scaffolding of the JudgeLoom platform. See `git log` for the full history of pre-release work.
