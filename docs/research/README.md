# 🔬 Research archive

Historical research that informed JudgeLoom’s design. These notes are written
in Vietnamese and are **not** operational documentation; versions, products, and
upstream projects may have changed since the snapshot date.

> [!NOTE]
> For current setup, use the [Quickstart](../getting-started/quickstart.md) and
> the [Documentation hub](../README.md).

## Documents

- [Open-source online judge landscape](open-source-online-judges.md) — DMOJ/VNOJ, CMS, DOMjudge, Hydro, Judge0, UOJ, QDUOJ, HustOJ, Themis, Testlib, Kattis, CCS API.
- [Commercial OJ UX teardown](commercial-oj-ux-teardown.md) — public product patterns from LeetCode, Codeforces, AtCoder, HackerRank, CodeChef, CSES, Kattis, SPOJ, Baekjoon and more.

## How to use this archive

- Treat it as **design context**, not as a promise that a pattern is implemented.
- Check the current source and the operational docs before integrating anything.
- Re-verify licenses and upstream behavior before copying or integrating code.
