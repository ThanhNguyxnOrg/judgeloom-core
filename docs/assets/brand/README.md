# 🎨 Brand assets

JudgeLoom’s identity is a **double-O ligature** that turns “Loom” into
interlocking loops. The over-under crossings make a distinctive mark that works
alone or inside the wordmark.

## Typography

**Inter Display Bold / Medium**. Lettering in the SVG deliverables is outlined
as vector paths, so no font installation is required to render them.

## Usage

- Prefer SVG for web and print; use PNG only where the platform requires it.
- Keep the mark’s clear space at least the width of one loop.
- Use the one-colour mark on busy or low-resolution backgrounds.
- Do not stretch, rotate, recolor outside the palette, or add effects.
