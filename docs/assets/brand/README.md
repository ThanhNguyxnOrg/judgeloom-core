JudgeLoom identity refresh

Deliverables
- judgeloom-logo.png / .svg: transparent horizontal logo lockup (1600x480).
- judgeloom-social-preview.png / .svg: GitHub social preview (1280x640).
- judgeloom-mark-mono.svg and mark-mono-16/24/32/64.png: one-colour and reduction proofs.

Concept
A custom double-O ligature turns the two letters in “Loom” into interlocking loops. The alternating over-under crossings create a distinctive woven signature that can stand alone as an icon or sit inside the wordmark.

Palette

Typography
